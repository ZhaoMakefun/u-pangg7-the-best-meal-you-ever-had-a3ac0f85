# The Best Meal You Ever Had

One remembered evening, one sentence: tomato soup and grilled cheese at grandmother's kitchen table, rain outside in October, the windows steaming up, and her pretending not to watch me finish every bite. No menu, no restaurant — just the meal that still wins.

## How to run

```sh
python3 main.py
```

The script checks the sentence is non-empty, a single line, valid UTF-8 and within the 200-character limit, then writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` when that variable is not set). Python 3 standard library only; every run produces identical output.
